# worldsim v0 design

Status: implementation contract, written before implementation. All regimes and rates are illustrative defaults, NOT measured facts. No private strategy or measured calibration is included.

## World <-> Engine contract

A World(config: WorldConfig, seed: int) is a lazy, exogenous-only generator. One instance produces N correlated contracts in one portfolio world; it never sees orders, inventory, arms or fills. Engine.run(world, arm) owns all execution and accounting. Independent worlds use seeds derived from (root_seed, world_index); arms reuse the same world seeds for paired comparisons.

Frame fields: ts_ms: int (elapsed milliseconds, sole clock); group: str ('perp' or 'prediction'); mid, best_bid, best_ask, tick_size: float64[N] (USD per contract); bid_px, ask_px: float64[N,D] (best first, USD); bid_size, ask_size: int64[N,D] (whole contracts); trade_price: float64[N] (USD); trade_size: int64[N] (whole contracts, zero means no print); aggressor: int8[N] (+1 taker buys, -1 taker sells); settlement_ms: int | None (known T); outcome: int8[N] | None (absent before T, then exactly 0/1); condition_id: int64[N]; is_no: bool[N]. Arrays are read-only. There is at most one exogenous print per contract per frame. A print is an independent counterfactual execution opportunity, not an order-book reconstruction.

Frames are at 0, dt_ms, ..., steps*dt_ms. Frame zero has no print. At t>0, prints execute against previously active orders before the new decision. The frame book is the observable book at t. Scheduled cancels effective at t win ties with prints; activations at t occur before prints. Decisions at t cannot consume that frame's prints, even at zero latency. Settlement supersedes all execution at T: clear all orders, pay positions, no decision or print at T. Perps have no settlement; the final frame still trades and the remaining position is marked, not economically liquidated.

Prediction belief is a private bounded martingale: b_next = b + a*b*(1-b)*tanh(z), 0<=a<=1, with symmetric zero-mean correlated innovations z. Slow/fast select a; the discretized displayed mid need not be an exact martingale. At T draw Bernoulli(b) using a shared/cluster/idiosyncratic Gaussian copula uniform. Pre-T displayed prices and quotes lie strictly in (0,1); T mid equals outcome exactly. Perp mid follows an arithmetic random walk, with no artificial upper/lower price bound; negative prices are permitted. Common and cluster variance weights sum to <=1; the remainder is idiosyncratic. Trades are directionally informed about the NEXT innovation with configurable probability adverse_selection, creating stale-quote adverse selection without leaking it to the arm. At the final trading frame the next innovation may instead precede settlement. Paired prediction mode requires even N: adjacent YES/NO contracts share condition_id, mirrored books/prints and outcomes summing to one. N counts contracts, not conditions; default N contracts are distinct YES conditions.

Determinism: identical seed, configs, arm parameters, code and numpy/polars versions on the same platform produce byte-identical numerical arrays and deterministic CSV/parquet/summary artifacts. No wall-clock timestamps or runtime measurements enter those artifacts; runtime is printed separately. Cross-version/platform bit identity is not promised. Changing N need not preserve market prefixes. World enumeration is stable; no global RNG, network, or data downloads.

## Arm contract

An Arm is a frozen dataclass with public scalar parameters (dataclasses.asdict is its sweep manifest), levels: int, and decide(snapshot: Snapshot) -> Intent. It is a pure decision function: no mutation, RNG, I/O, history outside the snapshot, future fields, latent belief, future outcomes, or other arms. This is an API isolation contract, not a security sandbox.

Snapshot fields: frame: Frame with only current observable fields; inventory: int64[N] (signed contracts); cash: int64[N] (nanodollars); order_price: float64[N,2,L] (USD, NaN means absent); order_size: int64[N,2,L]; order_status: int8[N,2,L] (0 absent, 1 in flight, 2 active, 3 cancel pending); last_fill_mid: float64[N] (NaN until first fill, then observable mid at last fill); time_to_settlement_ms: int | None. All arrays are read-only copies or immutable world arrays. Side axis 0 is bid/buy, 1 is ask/sell. Level identity is stable within a side.

Intent fields: action: int8[N,2,L] (0 keep, 1 post/replace, 2 cancel); price: float64[N,2,L]; size: int64[N,2,L] (positive whole contracts for action 1); price_mode: str ('absolute' or 'offset'); taker_size: int64[N] | None (signed contracts, positive buy). In offset mode price is a nonnegative integer number of ticks from current mid: bid = mid-offset*tick, ask = mid+offset*tick. Absolute and computed prices round outward to the tick (bid down, ask up). Invalid/nonfinite sizes, actions, off-grid offsets, prediction bounds, crossing own ladders, or non-monotone ladders raise ValueError. Distinct active quotes are ordered best to worst. Two reference arms expose size, levels, width_ticks, inventory_limit and skew_ticks (churn) or stop_ms (carry); reference arms use absolute prices. Sweeps instantiate frozen dataclasses with different parameters and use common world seeds.

Post on an empty slot starts activation latency. Replacement first cancels the old order, which remains fillable, then submits the replacement after cancel acknowledgement; activation latency starts then. A pending transition cannot be overwritten (new intents for that slot are ignored until complete). Repeating an identical live price and remaining size is a no-op. Cancel removes an in-flight post immediately; cancel of a live order takes cancel latency. Optional taker_size executes immediately against displayed top-N depth, best first, with partial execution and remainder dropped; it does not modify the exogenous world. Taker fees apply. Takers cannot execute at or after settlement.

## Fill semantics

Maker buy fills when a SELL print price <= quote; maker sell when BUY print price >= quote. Execute at resting price, limited by remaining print volume and own order quantity. Process own levels in price priority; volume is shared across levels, never duplicated. No fills solely because the book moves through an already active order.

queue_fraction >= 0 is a pessimism multiplier; default 0 is front-of-queue. On activation snapshot displayed same-side size at each price better than or equal to the quote, multiplied by queue_fraction and rounded up. Each eligible print consumes queue ahead before own size; cumulative queue consumption is shared across the ladder, so displayed depth is not counted twice. Queue does not replenish while the order rests. This is a deliberately conservative finite-depth proxy, not matching-engine queue reconstruction.

post_ms and cancel_ms are nonnegative integers, rounded UP to the next observed frame by event processing. An in-flight bid is permanently rejected if any observed opposite ask <= price from submission through activation (ask symmetric). Even if the book recovers before activation, rejection persists. Zero-latency posts are checked against the current touch and become active after that frame's prints. Cancel-pending orders remain fillable strictly before cancel acknowledgement. Replacement carries the old queue until acknowledgement, then resets queue. No interpolation between frames.

Prediction fees/rebates: abs(size)*p*(1-p)*rate USD, rounded once per executed fill to nearest nanodollar, ties to even. Maker receives maker_rate; taker pays taker_rate, never both. Compute p*(1-p) from integer microdollar prices for exact p -> 1-p symmetry. Perp fees use abs(size*price)*rate. Rates are nonnegative fractions, not bps. Settlement and terminal marks have no fees.

## Ledger + settlement contract

Quantities are whole contracts (v0 constraint). Prices quantize to microdollars; tick sizes must be positive multiples of 1e-6 USD, and prediction ticks must divide $1 exactly. Accounting uses signed int64 nanodollars, with checked conservative overflow bounds. Cash starts at zero; buy dq>0 changes cash by -dq*price plus rebate minus fee, inventory by dq. No collateral, margin, funding or market impact is modeled.

Maintain signed inventory and total absolute-position cost basis in nanodollars. Same-direction additions add cost. A reducing fill allocates total basis in proportion to closed quantity (average cost), rounding to nearest nanodollar, ties to even; any remainder stays with the open lot. Crossing zero closes the old lot and opens the residual at execution price. RoundTrip stores market: int, ts_ms: int, qty: int, entry_cost: int, exit_value: int, pnl: int, kind: str ('trade', 'mark', 'settlement'), all monetary fields in nanodollars. Short PnL reverses the value-minus-cost sign. This quantized average-cost convention avoids false binary-float zero-tolerance promises.

At end of perp run, add an attribution-only mark RoundTrip for residual inventory; inventory and cash remain unchanged. At prediction T credit q*Y dollars to cash, set inventory and basis to zero, and record settlement RoundTrips. Long YES plus long NO of the same condition pays exactly $1 per paired contract regardless of Y. Short YES at p and long NO at 1-p have equal terminal profit, but different initial cash; do not silently identify their cash balances.

For every market and portfolio, in integer nanodollars with zero tolerance:

    sum(roundtrip.pnl) == final_pnl + fees_paid - rebates_received
    final_pnl == cash + inventory * final_mark_nanodollars

The fast path accumulates roundtrip.pnl without allocating Python rows. Collect.NONE keeps totals only; Collect.FILLS additionally retains fills and roundtrips; Collect.ALL also stores per-frame equity. These modes must have identical scalar results. Floating USD artifact columns are for display only; *_nano integer columns are authoritative. Markout analytics are deferred; any future excursion window must be left-closed [t0,t0+h), never accessible to the arm.

## Portfolio aggregation and implementation layout

Modules: contracts.py (typed immutable boundary), worlds.py (two generators in one shared factor implementation), arms.py (two generic policies), fills.py (order state machine), fees.py (symmetric charges), ledger.py (vectorized exact accounting), engine.py (single clock/collection), portfolio.py (world harness and aggregation), cli.py and __main__.py. numpy hot loops vectorize N contracts; loops are only over time, worlds, sides and small depth/ladder axes. polars frames hold artifacts.

Per world: combined PnL, fees/rebates, peak-to-trough drawdown from initial zero equity, market-level terminal PnL. Concentration is max(abs(market PnL))/sum(abs(market PnL)) and HHI of those absolute contributions (zero if denominator zero). Uncertainty uses worlds, not markets: sample sd (null for one world), mean standard error and 95% Wilson interval for P(PnL>0). Exactly zero is not positive. Breadth uses a seed-fixed permutation of contract IDs, then nested prefixes N=5,10,...,500 capped at available contracts (also full N). Each point sums the SAME subset across independent worlds; report P(sum>0), Wilson bounds, mean and sd. This is not an IID resampling confidence interval and paired mode counts contracts, including complementary pairs.

CLI: uv run --offline --no-sync python -m quant_research.worldsim run --group both --markets 500 --worlds 100 --seed 7 --out runs/worldsim-<tag>/. Defaults: both reference arms, 240 steps of 250ms (60 simulated seconds), depth 3, slow prediction information, front queue, zero latency. CLI exposes regime/correlation/adverse/latency/fees/steps/arm/paired controls; Python dataclasses cover remaining sweeps. Refuse existing output directory. No pyproject edit or entry-point installation is needed; a bare `worldsim` entry point is deferred because the brief forbids pyproject edits/installs.

Artifacts: config.json; markets.parquet/csv; worlds.parquet/csv; breadth.parquet/csv; summary.md. Run metadata is configuration-only and deterministic. Runtime prints to stdout, outside deterministic artifacts. Benchmark the stated 500x100 command with BOTH groups and BOTH arms, clearly noting the 60-second simulated horizon. No claim about arbitrary horizons.

Face validity: correlation settings support near-independent and clustered innovations/outcomes, reducing diversification under clustered risk. The supplied empirical probabilities and stale-quote drain are not embedded or advertised as calibrations. Tests check correlation ordering and breadth math, not a fitted numerical reproduction of private observations. Parameter calibration, continuous sizes, heterogeneous settlement clocks, full queue replenishment and funding are outside v0.

## Display layer (fill-model upgrade; intentional model change)
The latent fair process (belief / arithmetic value), sizes, flow direction and penetration draws use the main per-world stream and are bit-identical to the pre-upgrade world for the same seed; they do not depend on any display knob. The display layer draws from an independent per-world stream (`Generator(PCG64(SeedSequence([seed, 0xD15])))`), so historical goldens differ BY DESIGN (displayed book, mids and prints changed), not because the latent changed.
- Spread: per market per frame NegBin in ticks (`spread_mean_ticks`=12, `spread_dispersion`=4, var = mean + mean^2/k; gamma-Poisson). Touch = displayed centre -/+ ceil(max(s,1)/2) ticks (outward), so the realised spread is an even number >= 2 ticks; depth levels extend outward. Prediction: the half-spread is capped and the centre clipped so the ladder stays strictly inside (0,1).
- Dislocation: displayed centre = latent + eta, eta stationary OU(0, `dislocation_sd_ticks`) with half-life `dislocation_halflife_ms`; the Frame `mid` is the displayed centre. At T the mid equals the outcome exactly.
- Prints: aggressor-side touch + w ticks; w = penetration (0..depth+1) w.p. 1 - `wick_prob`, else depth+2+ceil(Exp(`wick_scale_ticks`)) capped at `wick_max_ticks`. Fill semantics are unchanged (a maker buy fills when a sell print price <= quote), so a wick sweeps every rung at or beyond it.
- Toxicity: a print is informed (aggressor = sign of the next latent move) w.p. min(1, adverse_selection * `informed_strength` * m), m = `wick_toxicity_mult` for wicks, else 1. `informed_strength` = 1 and `dislocation_sd_ticks` = 0 recovers the legacy coupling.
- Default `tick` is now group-dependent (perp 0.01 = 1 bp on value 100; prediction 0.001); pass `tick` explicitly to override.
- Calibration (tests/fillmodel_calibration.py) targets the HL indep_calm regime: near-touch markout -1.7 +/- 1.0 bps, far-fill markout +5..+15 bps, spread mean 8-20 bps.
